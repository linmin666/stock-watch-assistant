# 股票盯盘助手

A 股均线信号监控工具：监控指定股票的 5 分钟 K 线，当出现 **MA30 上穿 MA60（均线金叉）** 或 **收盘价上穿 MA60（突破）** 时，通过微信（Server酱 / PushPlus）实时推送提醒。

## 功能

- **监控管理**：输入 6 位股票代码（自动识别沪深北）添加/移除监控，实时查看价格、MA30/MA60、均线状态
- **信号检测**：交易时段每 30 秒轮询 5 分钟 K 线，只检测「刚刚上穿」动作，幂等去重（同一根 K 线同一信号只推送一次）
- **微信推送**：支持 Server酱 / PushPlus，同一根 K 线两类信号合并为一条消息；推送失败自动补偿重发
- **信号历史**：时间线展示历史信号，支持按股票/类型筛选

## 运行

```bash
npm install

# 生产模式（推荐，单端口 3000，托管前端 + API + 监控引擎）
npm run build
npm start

# 开发模式（两个终端）
npm run dev:server   # 后端 API + 引擎 :3000
npm run dev          # 前端 Vite :5173（代理 /api）
```

打开 http://localhost:3000 ，在「设置」页配置 Server酱 SendKey 或 PushPlus Token（微信扫码即可获取），点「发送测试消息」验证。

## 交易时段

周一至周五 9:30–11:30、13:00–15:00（北京时间）内轮询；午休/收盘自动休眠，收盘后对未推送信号做一次补偿推送。

## 数据与隐私

- 行情数据源：新浪财经 5 分钟 K 线 + 腾讯行情名称解析（免 Key）
- 所有数据存于本地 SQLite（`data/stock-watch.db`），Key 不上传
